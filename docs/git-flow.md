# Git Flow simplificado\n\n## Ramas\n- main: estable y versionada.\n- develop: integración.\n- feature/<alcance>: trabajo por funcionalidad.\n- fix/<alcance>, release/vX.Y.Z, hotfix/<alcance> (opcionales según avance).\n\n## Convenciones de commit\nConventional Commits:\n- feat(scope): nueva funcionalidad\n- fix(scope): corrección\n- chore(scope): tareas de soporte\n- docs(scope): documentación\n- test(scope): pruebas\n- refactor(scope): refactorización\n\n## Flujo\n1. Crear rama desde develop: git checkout -b feature/products-scaffold\n2. Commits pequeños y descriptivos.\n3. Abrir PR a develop.\n4. Merge cuando tests pasen y checklist OK.\n5. Releases: branch release/ -> PR a main + tag.\n
